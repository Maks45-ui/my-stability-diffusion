# Подписанные обновления Flow

Кнопка «Проверить» в настройках читает `latest.json` последнего GitHub Release. Tauri проверяет цифровую подпись установщика перед установкой. Публикация выпуска требует приватный ключ; он **не должен** попадать в репозиторий или артефакты CI.

Публичный ключ уже записан в `src-tauri/tauri.conf.json`. Приватный ключ этого проекта хранится локально вне репозитория: `C:\Users\maksi\Documents\Codex\Flow-updater.key`. Сделайте резервную копию в безопасном месте. В настройках репозитория GitHub создайте Actions secret `TAURI_SIGNING_PRIVATE_KEY` со всем содержимым файла ключа. Ключ создан без пароля; секрет `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` не требуется.

Когда код версии 1.2.0 проверен, создайте и отправьте тег `v1.2.0`. GitHub Actions соберёт подписанный NSIS-установщик, приложит `.sig` и `latest.json` к выпуску. Обычные push/PR собирают неподписанный тестовый установщик. После первого подписанного выпуска кнопка обновления начнёт устанавливать новые версии. Версию в `package.json`, `src-tauri/Cargo.toml` и `src-tauri/tauri.conf.json` нужно менять согласованно.

Загружаемые при установке Forge Neo инструменты Git и uv закреплены по версиям и SHA256 в `src-tauri/src/managed_tools.rs`. Менять версию и хеш следует одновременно.
