# 🌊Flow

🌊Flow — это производительный десктопный менеджер для ИИ-пакетов и моделей Civitai, созданный на базе TypeScript, CSS и Tauri v2.

## ⚠️Требования к системе

Перед началом работы убедитесь, что ваш ПК соответствует минимальным требованиям и установлены необходимый инструментарий и компоненты:

- **Видеокарта:** Графический процессор NVIDIA с минимальным объёмом видеопамяти (VRAM) 4 ГБ.
- **Git:** [Git — Install for Windows](https://git-scm.com/download/win)
- **Python:** [Python Release Python 3.10.0 | Python.org](https://www.python.org/downloads/release/python-3100/) *(при установке обязательно поставьте галочку «Add Python to PATH»)*

## ❤️Особенности

- **Современный дизайн:** Элегантный интерфейс, кастомные темы (Светлая, Тёмная, Системная, Заказ, Багровая Луна, Синелетовые сумерки) и плавные анимации с поддержкой режима уменьшения движения (reduced-motion).
- **Встроенная консоль логов:** Полный отказ от сторонних окон CMD и терминалов. Все логи установки и работы процессов стримятся напрямую в выдвижную панель внутри приложения.
- **Первый запуск:** После приветственной анимации Flow один раз показывает инструкцию по получению API-ключа Civitai. Можно сохранить ключ или пропустить шаг. Выбор записывается в локальный `settings.json`; позже ключ можно добавить или заменить в разделе «Настройки».
- **Динамическое управление:** Интерактивная кнопка Запустить/Остановить с отслеживанием статуса процесса в реальном времени через события бэкенда на Rust.
- **Настройки пакета:** Встроенное модальное окно «WebUI Settings» для управления аргументами командной строки (`--lowvram`, `--xformers`, `--medvram` и др.) с помощью удобных интерактивных тегов.
- **Профиль SDXL для 4 ГБ:** Кнопка добавляет `--lowvram` и `--opt-sub-quad-attention`. Отдельный переключатель задаёт параметры CUDA-аллокатора PyTorch только процессу WebUI и при следующем запуске выставляет в `sd-webui/config.json` один загруженный чекпоинт, отключая кэши чекпоинтов и VAE. Опция `--medvram-sdxl` доступна вручную для менее строгого режима. Настройки памяти WebUI, однажды записанные в `config.json`, можно изменить в самом WebUI.
- **xformers:** В настройках пакета можно проверить импорт `xformers` из его venv и установить совместимую версию через штатный `launch.py` WebUI. После установки включите `--xformers` вместо другого флага attention и перезапустите пакет.
- **Загрузка моделей:** Очередь скачивания моделей с Civitai с докачкой, отображением скорости, оставшегося времени, возможностью паузы, возобновления и управления API-ключом.

## Диагностика запуска WebUI

Flow открывает WebUI во внешнем браузере. Адрес появляется в карточке пакета после того, как сервер сообщил локальный URL и проработал ещё 1,5 секунды. Лог запуска сохраняется в папке локальных данных Flow, в подкаталоге `logs`; точный путь выводится во встроенной консоли. Если WebUI завершится с `0xC0000005`, сохраните последние строки этого журнала и запись об ошибке Python из журнала событий Windows: один код завершения не показывает, какой модуль вызвал сбой.

Если подозреваете проблему аппаратного ускорения окна Flow, запустите `Flow.exe --flow-software-rendering`. Эта диагностическая опция добавляет `--disable-gpu` только для WebView2 приложения Flow и действует до следующего запуска. Альтернативно перед запуском можно задать переменную окружения `FLOW_WEBVIEW2_SOFTWARE_RENDERING=1`. Обычный запуск сохраняет аппаратное ускорение.
